# Techniki generowania pomysłów

---

## SCAMPER - Modyfikacja istniejącego

### Cel
Wygenerować warianty istniejącego rozwiązania przez 7 systematycznych pytań.

### Kiedy stosować
- Masz coś, co działa, ale chcesz więcej
- Konkurencja ma rozwiązanie do prześcignięcia
- Potrzebujesz ewolucji, nie rewolucji

### Proces - 7 pytań

**S - Substitute (Zamień):** Co mogę zamienić? (materiały, procesy, ludzie, miejsca)

**C - Combine (Połącz):** Co mogę połączyć? (funkcje, produkty, cechy)

**A - Adapt (Dostosuj):** Co mogę zaadaptować z innych dziedzin? (inne branże, natura)

**M - Modify (Zmodyfikuj):** Co mogę zmienić? (wielkość, kształt, tempo, częstotliwość)

**P - Put to other uses (Użyj inaczej):** Do czego jeszcze to może służyć? (inne grupy, konteksty)

**E - Eliminate (Usuń):** Co mogę uprościć lub usunąć? (funkcje zbędne, kroki, złożoność)

**R - Reverse (Odwróć):** Co jeśli zrobię na odwrót? (kolejność, perspektywa, role)

### Template
```
ISTNIEJĄCE: [co ulepszasz]

S - Zamień [X] na [Y]: [pomysł]
C - Połącz [X] z [Y]: [pomysł]
A - Zaadaptuj z [branża]: [pomysł]
M - Zmień [wielkość/tempo]: [pomysł]
P - Użyj dla [inna grupa]: [pomysł]
E - Usuń [zbędna funkcja]: [pomysł]
R - Odwróć [proces]: [pomysł]

TOP 3 POMYSŁY: [...]
```

## 5 Why - Odkryj źródło problemu

### Cel
Dotrzeć do źródłowej przyczyny, by rozwiązać prawdziwy problem, nie symptomy.

### Kiedy stosować
- Rozwiązujesz symptomy, nie przyczyny
- Problem się powtarza mimo "napraw"
- Nie jesteś pewien, co tak naprawdę trzeba naprawić

### Proces
1. **Zdefiniuj problem** - Konkretny, obserwowany problem
2. **Pytaj "Dlaczego?" 5 razy** - Dla każdej odpowiedzi, zadaj ponownie
3. **Źródło** - Po 5 "dlaczego" zazwyczaj docierasz do źródła
4. **Rozwiązanie** - Adresuj źródło, nie symptomy

### Template
```
PROBLEM: [konkretny, mierzalny]

1. Dlaczego [problem]? → [przyczyna 1]
2. Dlaczego [przyczyna 1]? → [przyczyna 2]
3. Dlaczego [przyczyna 2]? → [przyczyna 3]
4. Dlaczego [przyczyna 3]? → [przyczyna 4]
5. Dlaczego [przyczyna 4]? → [ŹRÓDŁO]

ŹRÓDŁO: [przyczyna 5]
ROZWIĄZANIE: [adresuj źródło, nie symptom]
```

### Przykład
```
Problem: Strona ładuje się 8 sekund
Dlaczego? → Obrazy za duże
Dlaczego? → Brak kompresji
Dlaczego? → CMS nie ma tej funkcji
Dlaczego? → Stary CMS z 2015
Dlaczego? → Strach przed migracją
ŹRÓDŁO: Strach przed migracją
ROZWIĄZANIE: Plan bezpiecznej migracji (nie kompresja ręczna)
```

## Lateral Thinking - Przełomowe pomysły

### Cel
Przełamać wzorce myślenia przez prowokacje i losowe połączenia.

### Kiedy stosować
- Wszystkie pomysły są "mniej więcej takie same"
- Potrzebujesz przełomu, nie inkrementu
- Tradycyjne podejścia nie działają

### Techniki

**1. PROWOKACJA**
Format: "Po: [absurdalne założenie]"
Pytanie: "Co ciekawego w tym jest?"

Przykład:
- Po: Restauracja bez jedzenia
- Co ciekawego? → Może chodzi o doświadczenie?
- Pomysł: Ghost kitchen, meal kits, immersive dining

**2. ESCAPE (Ucieczka od założeń)**
- Wypisz założenia
- Wybierz fundamentalne
- Pytaj: "Co gdyby to było fałszywe?"

Przykład:
- Założenie: Zegarek pokazuje czas
- Escape: Co gdyby nie pokazywał?
- Pomysł: Fitness tracker, fashion accessory

**3. RANDOM INPUT**
- Losowe słowo → cechy → wymuszone połączenia
- (Zobacz technikę Random Input poniżej dla szczegółów)

### Template - Prowokacja
```
PROBLEM: [...]

PROWOKACJA: Po: [absurdalne założenie]
Co ciekawego? → [insight]
Pomysł → [konkretny pomysł]

TOP 3 POMYSŁY: [...]
```

## Six Thinking Hats - 6 perspektyw

### Cel
Spojrzeć na problem z 6 różnych perspektyw systematycznie.

### Kiedy stosować
- Zespół myśli tylko w jeden sposób
- Konflikty między optymistami a pesymistami
- Potrzebujesz pełnego obrazu przed decyzją

### 6 kapeluszy

| Kolor | Perspektywa | Pytanie |
|-------|-------------|---------|
| 🤍 Biały | Fakty | Co wiemy? Jakie dane? |
| 🔴 Czerwony | Emocje | Co czuję? Intuicja? |
| ⚫ Czarny | Krytyka | Co może nie zadziałać? |
| 💛 Żółty | Korzyści | Dlaczego to zadziała? |
| 💚 Zielony | Kreatywność | Jakie alternatywy? |
| 🔵 Niebieski | Proces | Jaki plan? Synteza? |

### Rekomendowana kolejność
```
🔵 NIEBIESKI - Otwarcie (cel, agenda)
🤍 BIAŁY - Fakty
💚 ZIELONY - Pomysły
💛 ŻÓŁTY - Plusy
⚫ CZARNY - Minusy
🔴 CZERWONY - Intuicja (30s każdy)
🔵 NIEBIESKI - Zamknięcie (synteza, decyzja)
```

### Template
```
PROBLEM: [...]

🤍 BIAŁY - Fakty: [co wiemy]
🔴 CZERWONY - Intuicja: [gut feeling]
⚫ CZARNY - Ryzyka: [co może nie zadziałać]
💛 ŻÓŁTY - Korzyści: [plusy]
💚 ZIELONY - Alternatywy: [opcje]
🔵 NIEBIESKI - Synteza: [co wiemy, decyzja, next steps]
```

## Random Input - Losowa inspiracja

### Cel
Wymusić nieoczekiwane połączenia przez całkowicie losowy bodziec.

### Kiedy stosować
- Całkowita blokada pomysłów
- Wszystkie pomysły są nudne/przewidywalne
- Potrzebujesz szybkiej inspiracji (5-10 minut)

### Proces
1. **Losowe słowo** - Książka, Wikipedia random, przedmiot z pokoju, generator słów
2. **Wypisz cechy** (5-10) - Właściwości, funkcje, skojarzenia
3. **Wymuszone połączenia** - "Jak [cecha] może rozwiązać [problem]?"
4. **Top 3** - Najbardziej obiecujące

### Źródła losowości
- Losowa strona w książce/słowniku
- https://en.wikipedia.org/wiki/Special:Random
- Przedmiot z pokoju (wskaż palcem)
- https://randomwordgenerator.com/

### Template
```
PROBLEM: [...]

RANDOM WORD: [losowe słowo]

CECHY:
1. [cecha]
2. [cecha]
3. [cecha]
4. [cecha]
5. [cecha]

POŁĄCZENIA:
1. [cecha] → [jak rozwiązuje problem?]
2. [cecha] → [jak rozwiązuje problem?]
3. [cecha] → [jak rozwiązuje problem?]
[...dla każdej]

TOP 3 POMYSŁY: [...]
```

### Przykład
```
PROBLEM: Jak zwiększyć engagement w fitness app?
RANDOM: DRZEWO

CECHY:
1. Rośnie powoli
2. Ma głębokie korzenie
3. Rozgałęzia się
4. Zmienia się sezonowo
5. Daje cień

POŁĄCZENIA:
1. Rośnie → Gamifikacja wzrostu (visualize progress)
2. Korzenie → Strong onboarding fundamentals
3. Rozgałęzia → Content recommendations rozwija się
4. Sezonowe → Features zmieniają się z porą roku
5. Cień → Digital wellness features

TOP 3: Growth visualization, Strong onboarding, Digital wellness mode
```

## Zasady ogólne dla wszystkich technik

- Generuj bez oceniania (ilość przed jakością)
- Zapisuj WSZYSTKIE pomysły, nawet absurdalne
- Wybierz top 3-5 dopiero na końcu
- Przejdź potem do WALIDACJI (references/walidacja.md)
